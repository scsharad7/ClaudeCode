# Archive: live-action plan

These documents planned a **live-action** proof-of-concept short with a hired crew
(stunt team, DP and so on). The project switched to an **AI-generated** film in October 2026,
so they are no longer the active plan. See [../../GAMEPLAN.md](../../GAMEPLAN.md).

They're kept because much of the thinking still applies if you ever shoot live action,
for example filming your own motion reference or a live-action/AI hybrid. The safety rules in
[fights/stunt-plan.md](fights/stunt-plan.md) apply to any real-world filming you do.

Relative links inside these files may point to locations that have since changed.
